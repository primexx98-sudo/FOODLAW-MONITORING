# 식품 법령 개정 모니터

식약처·법제처·식품안전나라의 식품 법령 개정 공고를 매주 자동 수집해 아카이브하는 시스템입니다.

**사이트**: https://primexx98-sudo.github.io/FOODLAW-MONITORING/

## 빠른 시작

1. 이 저장소를 GitHub에 push
2. Settings → Pages → `/docs` 폴더로 배포 설정
3. Settings → Secrets → `LAW_API_KEY` 등록 (법제처 OpenAPI 키)
4. Actions → `주간 식품 법령 수집` → `Run workflow` 로 첫 실행

자세한 내용은 `설계서.md` 참고.
